# 背景画像（images/）

予想累計滞在時間に応じて切り替わる背景画像をここに置きます。
ビルド時にアプリへ同梱されます。**ファイル名は下記のとおりにしてください**（`.jpg` 推奨）。

| ファイル名      | 表示条件（1月末の予想累計）           | イメージ                         |
| --------------- | ------------------------------------ | -------------------------------- |
| `bg-low.jpg`    | **350時間未満**                      | ①トランプ「研究成果ゼロ」        |
| `bg-mid.jpg`    | **350時間以上 450時間未満**          | ②泣く女の子                      |
| `bg-high.jpg`   | **450時間以上**                      | ③高市氏「研究して研究して…」     |

- 画像が無い場合でもアプリは動作します（その場合は段階ごとに異なる**背景色**が表示されます）。
- 推奨サイズ: 横長（例 1600×900 以上）。アプリ側で `cover` 表示され、上に暗いオーバーレイがかかります。
- 差し替えたい場合はファイルを置き換えて、再度インストーラーをビルドしてください。
